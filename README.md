  <h1>🛍️ Fashion eCommerce Shop</h1>
  <h3>Built with React.js, TypeScript & JSON Server</h3>

  <p>
    The <strong>Fashion eCommerce Shop</strong> is a modern and responsive web application
    developed using <strong>React.js best practices</strong>.
    This project focuses on clean UI design, smooth navigation,
    and a scalable front-end architecture suitable for academic and learning purposes.
  </p>

  <p>
    The application simulates an online fashion store where users can browse products,
    view detailed information, manage their cart, and proceed through a checkout flow.
  </p>

  <hr />

  <h2>📌 Project Description</h2>
  <p>
    This project represents a fashion-focused eCommerce platform designed with
    a minimal and elegant user interface.
    Although styled as a luxury fashion store, the structure can be adapted
    for men’s, women’s, kids’, or general clothing stores.
  </p>

  <hr />

  <h2>✨ Features</h2>
  <ul>
    <li>Landing page with featured products</li>
    <li>Shop page with product listings</li>
    <li>Search functionality</li>
    <li>Single product details page</li>
    <li>Cart management</li>
    <li>Login & registration pages (UI-based)</li>
    <li>User profile & order history</li>
    <li>Checkout page</li>
    <li>Toast notifications</li>
    <li>Fully responsive design</li>
  </ul>

  <hr />

  <h2>🛠️ Technologies Used</h2>
  <ul>
    <li>React.js – Component-based front-end library</li>
    <li>TypeScript – Static typing for scalable code</li>
    <li>Redux Toolkit – Global state management</li>
    <li>React Router DOM – Client-side routing</li>
    <li>Tailwind CSS – Utility-first CSS framework</li>
    <li>Axios – HTTP client for API handling</li>
    <li>JSON Server – Mock REST API backend</li>
    <li>React Hot Toast – Notification system</li>
    <li>Concurrently – Run multiple scripts simultaneously</li>
  </ul>

  <hr />

  <h2>📁 Project Setup & Installation</h2>

  <h3>1️⃣ Prerequisites</h3>
  <p>
    Ensure <strong>Node.js</strong> and <strong>npm</strong> are installed.<br />
    Download from:
    <a href="https://nodejs.org/" target="_blank">https://nodejs.org/</a>
  </p>

  <h3>2️⃣ Install Dependencies</h3>
  <pre>
npm install
  </pre>

  <h3>3️⃣ Run the Application</h3>
  <pre>
npm start
  </pre>
  <p>The app runs at <strong>http://localhost:3000</strong></p>

  <h3>4️⃣ Run JSON Server (Optional)</h3>
  <pre>
npm run server
  </pre>
